# Roadmap and release slices

## 0.1 — Local continuity

Rust Core, Tauri Desktop, ACP harness, durable threads, permissions,
projects at a minimal level, identity documents, and local memory.

## 0.2 — Personal Vault

Encrypted device pairing, knowledge/document sync, provenance across devices,
revocation, recovery, and a self-hostable relay.

## 0.3 — Personal runtime

Skills, MCP management, scheduler/heartbeat, richer project workbench, memory
curation, and optional attachment synchronization.

## Later

Terminal and Codex app-server harnesses, bounded multi-agent coordination,
Altior Native Harness, local/provider model routing, voice, mobile companion,
extension SDK, peer-to-peer transport, and user-controlled interoperable export.

Public promises must follow demonstrated acceptance results, not this aspirational
ordering. Protocol and storage versioning begins at 0.1 and remains migration-safe.
